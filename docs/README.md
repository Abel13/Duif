## Regras editoriais

- Milestones e status existem somente no roadmap ativo ou no histórico.
- Resultados datados de produção existem somente no histórico de releases.
- Procedimentos executáveis existem somente em operações.
- Guias ativos são escritos em pt-BR; identificadores e comandos preservam o idioma técnico.
- Documentos históricos não orientam implementação atual.
- Antes de criar um arquivo, verifique se a fonte proprietária existente deve ser atualizada.
